# /search - Find Opportunities

Run the `opportunity-search` skill (`.claude/skills/opportunity-search/SKILL.md`) and follow
it exactly. Pass `$ARGUMENTS` through as the focus (e.g. `biology`, `paid internships`, `local`,
`broad`, `next-year`).

If `profile.md` is missing or still has placeholders in **Basics**, stop and ask the student to run `/setup`
first - eligibility can't be checked without grade, age, location and citizenship.
