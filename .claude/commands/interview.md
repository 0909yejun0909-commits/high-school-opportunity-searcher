# /interview - Interview Prep

Input (`$ARGUMENTS`): the program (and interview date/format if known).

Load `opportunity-assistant/SKILL.md` and follow its **Interview prep** section. Use the
program's official pages (via `opportunity-fetcher` if not already in `applications/<slug>/`),
`profile.md`, and the student's submitted materials in `applications/<slug>/` so talking points
match what the interviewer has read. Save the prep sheet to `applications/<slug>/interview.md`,
then offer the mock interview. Mark the tracker: `python3 tools/opps.py track update --program
"<name>" --status interview`.
